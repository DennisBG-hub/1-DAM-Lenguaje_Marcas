Introducción

Bienvenido a la documentación oficial de WeatherAPI. Esta API permite consultar información meteorológica y de ubicación en tiempo real.

Para obtener información detallada de la API original, puedes Consultar documentación oficial (enlace externo).

Autenticación

Todas las peticiones a WeatherAPI requieren una clave de API (API Key) en la cabecera HTTP.

Para conocer más detalles sobre la protección de datos y el manejo de claves, revisa nuestra Política de seguridad (enlace externo).

Endpoint de usuarios

Permite gestionar las cuentas de usuario asociadas a la API.

GET /v1/users/me

Endpoint de ciudades

Permite consultar los datos meteorológicos por ciudad.

GET /v1/current.json?q=Madrid
